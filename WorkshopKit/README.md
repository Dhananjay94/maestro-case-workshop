# Workshop kit: what is where

## For participants
| Item | What it is |
|---|---|
| `Guide_Site/index.html` | The workshop as web pages: scenario, setup, building blocks, business rules, build guide, quick reference |
| `Participant_Build_Guide.md` | The same guide as one Markdown file |
| `Starter_Solution/` | `MotorClaimsWorkshop_Setup.uis` (import and run it in Studio Web) and `MotorClaims_Workshop.uis` (the workshop solution). See its README |
| `01_Data/` | Seed data and the claim values for the three test customers |
| `02_Documents/` | The PDFs for Rahul, Priya and Arjun |
| `CASE_FLOW_PLAN.md` | The routing plan: every transition and the rule behind it |

## For the facilitator
| Folder | What is in it |
|---|---|
| `Facilitator/` | Agendas, runbook, preflight checks, speaker notes, demo script, the email to organisers, the master plan |
| `Deck/` | The presentation deck |
| `Reference/` | Setup checklist, how to open the Intake App, and the per-component test guide |
